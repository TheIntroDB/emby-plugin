TheIntroDB

Segment data (intro, recap, credits, preview) is fetched from TheIntroDB API using each item's TMDB or IMDB ID. Segments are not loaded when you press play; run the TheIntroDB media segment scan scheduled task to populate them.

Optional Bearer token; when set, your pending and accepted submissions are weighted higher in results.

Maintenance

How often the plugin checks items it has segments for and restores TheIntroDB markers that Emby may have overwritten (e.g. when Emby regenerates placeholder chapters for files without embedded chapters). Set to 0 to disable automatic repair.

Tip: Emby's library setting "Generate chapters for videos that don't contain embedded chapter information" (Dashboard → Libraries → edit a library) can overwrite TheIntroDB markers on files without embedded chapters. Disabling it there prevents the overwrite entirely.
